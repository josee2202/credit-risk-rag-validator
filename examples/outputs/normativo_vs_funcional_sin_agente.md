> 4. Calibración
> 
> Cada año se compara la PD asignada a cada grado de rating con la tasa de default observada mediante el test binomial con un nivel de confianza del 95%. Las desviaciones significativas se analizan en el comité de modelos y se documentan junto con las acciones correctoras acordadas.
> 
> 5. Poder discriminante
> 
> El poder discriminante se mide anualmente con el AUC, que en la última revisión fue de 0,81. Se ha fijado un umbral mínimo de 0,70; si el AUC queda por debajo, el caso se escala al comité de riesgos para decidir si se recalibra o se redesarrolla el modelo.
